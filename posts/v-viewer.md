# v-viewer

v-viewer 是基于 [Viewer.js](https://github.com/fengyuanchen/viewerjs) 的 Vue 图片浏览组件，支持缩放、旋转、翻转和图片切换，提供组件、指令和 API 三种使用方式。

> 如有使用问题、Bug 反馈或功能建议，请到 [GitHub Issues](https://github.com/mirari/v-viewer/issues) 留言，请勿在本文评论区留言，以便集中跟进和处理。
