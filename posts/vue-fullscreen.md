# vue-fullscreen

vue-fullscreen 提供组件、指令和 API 三种使用方式，可以将整个页面或指定元素切换为全屏，支持浏览器原生全屏和网页全屏。

> 如有使用问题、Bug 反馈或功能建议，请到 [GitHub Issues](https://github.com/mirari/vue-fullscreen/issues) 留言，请勿在本文评论区留言，以便集中跟进和处理。
